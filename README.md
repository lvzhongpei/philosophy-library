# 哲学图书馆 · 深空档案

把二十二位哲学家的思想做成一片可以操作的星空。

每位哲学家有一份完整的档案——生平时间轴、流派定位、核心观点、代表著作、名言（原文与出处）、追问——外加**两个可以动手的思想实验**。另有一张**概念图谱**，把 113 个概念、195 条连线铺成一张可以拖动的网。

线上地址：<https://lvzhongpei.github.io/philosophy-library/>

## 概念图谱

`graph.html` 是一张力导向的概念网：

- **113 个概念**，冷色＝西方，暖色＝中国；
- **195 条连线**，其中 **22 条跨传统**（暖色虚线）——道通向不可说、正名通向意义即用法、家族相似通向理念；
- 可以拖动节点、点开看解释、按哲学家筛选、一键重排；
- **时间轴**：点「沿时间播放」，概念会按哲学家出生的先后依次点亮，也可以直接拖动进度条跳到某一年。刚被点亮的那几条边会闪一下。

## 十组对话

`dialogue.html` 从 22 条跨传统连线里挑出 12 条，展开成十二篇短文。每一篇都是同一个结构：

- 甲、乙两侧各自的**原文与出处**；
- 两段正文：先讲他们在哪一点上其实是同一件事，再讲在哪一点上分道扬镳；
- 一句**追问**，不给答案。

不是「他们说了同样的话」，而是「他们在同一个问题上给出了不同的答案」——重合处不必惊喜，冲突处才有的看。

## 站点结构

```
.
├── index.html              星图首页（星图 ⇄ 名录，含年代筛选与全文搜索）
├── philosopher.html        详情页模板（?id=kant）
├── graph.html              概念图谱（含时间轴播放）
├── dialogue.html           十组对话
├── css/
│   ├── base.css            变量、排版、详情页骨架
│   ├── star.css            星图、名录卡片、年代滑杆
│   ├── graph.css           概念图谱
│   └── dialogue.css        十组对话
├── js/
│   ├── starfield.js        全站背景星尘
│   ├── starmap.js          星团布局、轨道绘制、筛选与视图切换
│   ├── render.js           详情页渲染
│   ├── canvas-kit.js       装置共用画布与控件
│   ├── graph.js            力导向布局、交互与时间轴
│   ├── dialogue.js         对话页渲染
│   └── devices/            二十四个交互装置，各一个文件
└── data/
    ├── philosophers.json   哲学家与概念（唯一内容源）
    └── dialogues.json      十组对话的正文
```

零依赖、零构建、无 CDN。所有图形都是 Canvas 现画的，没有一张位图。

## 本地预览

```bash
cd philosophy-library
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

> 直接双击 `index.html` 会失败：页面用 `fetch` 读取 JSON，`file://` 协议下会被浏览器拦截。

## 加一位哲学家

只需改 `data/philosophers.json`：

1. 在 `philosophers` 数组里加一个对象，字段照抄任意现有一项（`id`、`name`、`bio`、`ideas`、`works`、`quotes`、`questions`、`device`、`device2` 等）。
2. `cluster` 填 `clusters` 里已有的 id，或用新 id 并在 `clusters` 里补一项。
3. `device` / `device2` 填 `js/devices/` 里已有的装置 key，或在 `philosopher.html` 里引入新脚本、在 `window.DEVICES` 上注册一个 `mount({canvas, controls})`。
4. 想让它出现在图谱里，就在 `concepts` 数组里加概念，`links` 写关联概念的 id；反向连接会自动补齐。

星图坐标 `x`/`y` 只需要相对关系正确——页面会自动归一化铺满画布，窄屏则退回三列网格。

## 内容说明

- 引文均标注出处（卷、节或篇名）；西方原文保留德／法／希腊语，中国典籍保留文言。
- 译名为通行译法，原文以通行校勘本为准。
- 生平与观点为编译转述，非逐字翻译。
- 概念图谱中的连线是思想关联的示意，不是史学意义上的影响考据。
- 苏格拉底不著一字，其「代表著作」一栏列的是他人记述，页内有专门说明。
- 尼采部分特别说明：《权力意志》由妹妹伊丽莎白在身后编成并篡改，与尼采本人立场多有冲突，因此不作为其代表作列出。
